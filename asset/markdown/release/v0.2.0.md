# 让剪贴板成为入口

Welcome to AnyCloud v0.2.0!

AnyCloud v0.2.0 introduces Clipboard Pilot, a new workflow that watches copied links, matches them with user-defined policies, and turns matched content into a quick notification entry. This update also brings a Mihomo-friendly policy structure, Shizuku-based clipboard access, policy management, and several UI refinements for a smoother daily experience.

欢迎来到 AnyCloud v0.2.0！

AnyCloud v0.2.0 引入了 Clipboard Pilot：它可以监听复制的链接，根据用户配置的策略进行匹配，并将命中的内容转化为可快速行动的通知入口。本次更新也加入了更接近 Mihomo 使用习惯的策略结构、基于 Shizuku 的剪贴板访问能力、策略管理功能，以及一系列界面体验调整。

---

### What's New in v0.2.0

- **Clipboard Pilot**:
  - Added clipboard listening powered by Shizuku, allowing AnyCloud to react when copied content changes.
  - Added link parsing and policy matching for domain and domain-suffix rules.
  - Added clipboard logs, so recent matched and unmatched clipboard results can be reviewed in the app.
  - When a policy is matched, AnyCloud can push a temporary notification with a quick action to open the target app.

- **Policy Management**:
  - Added policy and policy-group management screens.
  - The rule model is now closer to Mihomo-style policy configuration, making it easier to understand for users familiar with rule-based routing.
  - Policies can be grouped and linked to target apps, preparing the foundation for more flexible routing and import workflows in future versions.
  - Added local persistence and swipe deletion for policies and groups.

- **UI Improvements**:
  - Added more Cloudy sampling hooks to reduce mismatches between blurred background content and the actual Cloud list after adding new items.
  - Reorganized the navigation drawer into clearer sections, with a list structure that leaves room for future entries.
  - Added more visible drawer buttons in the top app bar, making core navigation easier to discover.

### v0.2.0 更新内容

- **Clipboard Pilot**:
  - 新增基于 Shizuku 的剪贴板监听能力，让 AnyCloud 可以在复制内容变化后做出响应。
  - 新增链接解析与策略匹配，支持域名和域名后缀规则。
  - 新增剪贴板日志，可以在应用内查看最近的匹配与未匹配记录。
  - 当复制内容命中策略时，AnyCloud 可以推送一条临时通知，并提供快捷入口打开目标应用。

- **策略管理**:
  - 新增策略与策略组管理页面。
  - 规则模型开始向 Mihomo 风格的策略配置靠拢，熟悉规则分流的用户会更容易理解。
  - 策略可以归组，并关联到目标应用，为后续更灵活的分流、导入和扩展能力做好准备。
  - 策略和策略组支持本地保存，也可以在管理页面中滑动删除。

- **界面调整**:
  - 增加 Cloudy 的背景采样触发点，缓解新增 Cloud 后背景虚化内容与实际列表不同步的问题。
  - Drawer 增加区域分组，并改为更适合后续扩展的列表结构。
  - 主要页面加入更醒目的 TopAppBar 侧边栏入口，降低新用户的导航门槛。

---

### Current Limitations

- **IP/CIDR Rules**:
  - IP/CIDR policy type is not enabled yet. Current matching focuses on domain and domain-suffix rules.

### 目前欠缺

- **IP/CIDR 规则**:
  - IP/CIDR 规则暂未启用。当前版本的匹配能力主要集中在域名和域名后缀规则上。
