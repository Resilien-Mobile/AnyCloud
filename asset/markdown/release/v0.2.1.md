# 从链接导入策略

Welcome to AnyCloud v0.2.1!

This update introduces a Mihomo-like YAML policy subscription list for Clipboard Pilot. Enter its link to import policy groups and rules into AnyCloud, with clearer feedback if the import fails. `IP_CIDR` rules also gain initial support for exact IP matching.

欢迎来到 AnyCloud v0.2.1！

本次更新为 Clipboard Pilot 加入 Mihomo-like 风格的 YAML 策略订阅清单，让规则的组织和导入更符合使用习惯。输入清单链接，即可导入策略组和规则；导入失败时，应用也会说明原因。`IP_CIDR` 规则同时初步支持精确 IP 匹配。

---

### What's New in v0.2.1

- **Policy Import**: Added a Mihomo-like YAML subscription list. Import policy groups and rules from its link; existing groups with the same name are updated, while duplicate rules are skipped.
- **Matching and Feedback**: Added initial support for exact IP matching in `IP_CIDR` rules, along with clearer error messages for download, file format, or save failures.

### v0.2.1 更新内容

- **策略导入**：新增 Mihomo-like 风格的 YAML 订阅清单，让策略配置更符合使用习惯。支持通过链接导入策略组和规则；已有同名策略组会更新，重复规则不会再次添加。
- **匹配与提示**：`IP_CIDR` 规则初步支持精确 IP 匹配；下载、文件格式或保存出错时，会显示更明确的原因。
