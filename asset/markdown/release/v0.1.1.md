# 第一个稳定版

Welcome to AnyCloud v0.1.1!

AnyCloud v0.1.1 is the project's first stable release. This update completes previously unfinished controls and fixes usage-day tracking, making the core notification experience more reliable.

欢迎来到 AnyCloud v0.1.1！

AnyCloud v0.1.1 是项目的第一个稳定版本。本次更新补全了此前尚未完成的控制功能，并修复了使用天数统计问题，让核心通知体验更加可靠。

---

### What's New in v0.1.1

- **Notification Controls**:
  - **Power Cloud Switch**: Replaced the placeholder button with a functional switch. You can now turn the live power notification on or off; turning it off also stops updates and removes the notification.
  - **Ongoing Style**: The setting is now functional and remains saved after restarting the app. When enabled, the Task Cloud notification title shows the number of unfinished tasks instead of the default app name.
- **Usage-Day Tracking**:
  - Fixed an issue where cumulative usage days could not be tracked correctly. Starting from this update, AnyCloud will begin accumulating usage days normally.

### v0.1.1 更新内容

- **通知控制功能**:
  - **Power Cloud 开关**: 将原先的占位按钮替换为可用的开关。现在可以直接开启或关闭实时电量通知；关闭后，应用会停止更新并移除该通知。
  - **常驻样式 (Ongoing Style)**: 设置项现已正式生效，并会在应用重启后保留。开启后，Task Cloud 通知标题将显示未完成任务数，而不是默认的应用名称。
- **使用天数统计**:
  - 修复了累计使用天数无法正常统计的问题。从本次更新起，AnyCloud 将可以正常开始累加使用天数。
